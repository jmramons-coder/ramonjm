# Ramon JM — Portfolio

A quiet, mobile-first portfolio for selected application work.

## Local development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

The project is built with Next.js and is ready for Vercel deployment.

The site uses one continuous responsive flow: a concise introduction, a
horizontally scrollable application index, and six project cards for
PushedWorld, PatternViewer, Tracer, aBeam, CryptoCroc, and Equisoft Labs.
PushedWorld uses its real app icon and original website hero artwork. Its case
study at `/world` covers live counting, the 100-level Path, in-app setup
videos, on-device privacy, and the optional League, with a link to the full
product site. PatternViewer has a focused project page at `/patternviewer`
with a live product preview. aBeam uses its real animated mark and opens an
immersive project page at `/abeam`. CryptoCroc and Equisoft Labs include live,
framed previews of their public prototypes. A three-step workflow and a slow,
seamlessly looping logo marquee for Equisoft, FolksHR, PetalMD, and Peak Media
complete the page. The portfolio intentionally avoids invented project links
or unsupported claims.
