# Nudge and PushedWorld showcase audit

Audited October 24, 2026. The active project hubs, workspace drive, vault and build archive were searched before choosing the mobile portfolio widgets. Source files remain unchanged.

## Search coverage

The inventory used `rg --files --hidden --follow` for raster images, SVG, video, PDF and design-source extensions. It pruned dependency folders, Git internals, build products, derived data, package caches, simulator application bundles and language environments. AppleDouble `._*` entries and system trash/metadata were excluded from the counts below. Nudge/PushedWorld counts match their names anywhere in the path and identify candidates, rather than verified unique assets.

These are overlapping path inventories, not totals to add together: the active hubs resolve into the workspace drive, the vault contains copies/aliases, and campaign folders repeat originals. Nudge's active hub contains 254 PNG, 122 JPG, 71 MP4, 64 AVIF and 12 WebP paths. PushedWorld's contains 1,325 PNG, 134 JPG, 9 MP4 and 4 SVG paths. The archive's three Nudge matches were cached app icons, offering no useful showcase media.

Coverage is comprehensive for the readable media paths under the stated roots and exclusions. It does not imply that every candidate was opened. The vault's protected Spotlight metadata was unreadable. Several historical workspace/vault links were stale, as were PushedWorld's `tmp` and `Launch/StoreAssets` links; the archive also had stale simulator-photo links. Those failures were recorded during the scan and were not bypassed. No build/cache directories were needed for the curated results.

The review followed the source maps in [nudge-asset-sources.md](nudge-asset-sources.md) and [world-asset-sources.md](world-asset-sources.md), read the native capture/launch READMEs, inspected still-image contact sheets, and sampled candidate video frames with FFmpeg. New derived files live only in `public/showcase/nudge` and `public/showcase/world`.

## Delivery and motion

The native Nudge MP4 is copied unchanged (635,576 bytes). PushedWorld's selected excerpt is encoded to 416 × 712 at 24 fps, silent H.264 with a fast-start MP4 header (about 356 KB); the original recording content and aspect ratio are preserved. Posters and optimized artwork are local WebP. Product screenshot pixels are not inverted, recolored or filtered for dark mode.

`NudgeShowcase` delegates to `NudgePhoneShowcase`, using the shared native phone scenario player configured with Nudge's existing video, poster and icon. Its grid hides the local controls; deliberate playback is available in the expanded preview. PushedWorld's recording control, project footer and local rep demonstration remain unchanged. Native playback requires at least 20% stage visibility and a visible document. Global pause takes precedence. Reduced motion prevents ambient autoplay and expansion animation; explicitly opening the preview permits deliberate playback. Observers/listeners are cleaned up and recordings pause on unmount. The grid itself remains stationary.

The current phone-only Nudge pass passed the production build, TypeScript and targeted ESLint. Browser checks confirmed a transparent grid surface with no header, slider or local playback button; the sole grid button expands the phone. The expanded view contains the actual loaded Nudge icon and title at the top left, preserves the video position and returns focus on close. Its unchanged native file is 496 × 1078, 7.816667 seconds and loops as before. Exact CSS viewport widths of 320 and 390px retain the complete phone without page overflow. Global pause and reduced-motion behavior passed. The Nudge file streams with HTTP 206 over loopback and LAN. Shared-player regression confirmed Grok Safe remains 143.3 seconds with looping disabled. Results and screenshots are in `outputs/mobile-project-refresh/`.
