# Tracer website showcase

The portfolio uses full-page captures of the actual public English website, taken on October 28, 2026:

- Landing page: https://tracersecurity.ca/
- Labs: https://tracersecurity.ca/labs

Each page was captured at 1440 CSS pixels wide with optional analytics declined, in both native light and dark themes. The landing captures are 1440 × 6093; Labs captures are 1440 × 4399. WebP encoding preserves the full page and its original layout. No interface was recreated or retouched.

Assets live in `public/showcase/tracer-website/`. The grid gently pans the landing capture; opening it provides native vertical scrolling and Landing page / Labs tabs. The displayed capture follows the portfolio theme. Scroll positions are retained separately for both pages. Reduced motion disables the automatic pan and entry animation.

This is a visual walkthrough, not a live embedded website. Captures remain available independently of the source site's availability or framing policy. The Tracer header links to the canonical public website.
