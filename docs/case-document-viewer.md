# Contextual document inspection

The portfolio's agent-first workspace uses a browser-local document viewer. It is a design exploration with authored, fictional pages and findings, rather than a connection to the source application's document store or AI services.

Documents retain the same task / requirement / document context tabs. Their compact header links to the named requirement and its task action. Opening a document or a received requirement provides a wider dock by default while retaining manual resizing.

Actions list compact requirements without duplicating their attachments. The requirement has a distinct check-circle symbol; attachments retain the folded-page document symbol and are opened from the requirement or Documents table. A compact Links section uses the same record rows across actions, requirements and documents: a blue linked name and status at the right. Task and action form one wrapping path separated by a slash. A document links to its requirement; a requirement links to its supporting document. Task relations remain inside their actions.

Received and fulfilled requirements show the document canvas and its insight rail directly, without requiring a second navigation step. Ordered requirements show an empty evidence area, with no invented document or findings. The document tab retains the same viewer for file-focused inspection. Each record keeps its own viewer state.

The viewer pairs a document canvas with an insight rail. Page thumbnails change the selected page; zoom and drag-to-pan support closer inspection. Each finding cites a page and passage in the authored document, so a source selection reveals the evidence behind the finding. Selected page, zoom and citation remain local to the mounted document record until its contextual tab is cleared.

Task analysis cards, requirement findings, document insights and the assistant shortcut share the same animated lilac surface. Reduced-motion preferences stop the surface animation. Narrow document panels adapt the preview and findings to the available space.

No customer documents, model extraction, medical interpretation, production case updates or live AI execution are introduced by this portfolio interaction.
